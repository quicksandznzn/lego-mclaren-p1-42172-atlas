# lego-mclaren-p1-42172-atlas

An interactive 3D explorer of the LEGO® Technic McLaren P1™ (set 42172), with exploded views and individual part inspection.

Inspired by [Human Atlas](https://github.com/ashemag/human-atlas).

## Run locally

Requires Node.js 22.13 or later. Model assets are included.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

See [model assets](docs/model-assets.md) for sources and rebuilding instructions.
